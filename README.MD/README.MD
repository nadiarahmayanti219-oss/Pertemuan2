# To-Do List

Aplikasi To-Do List sederhana untuk mencatat dan mengelola tugas sehari-hari.

## Deskripsi

To-Do List merupakan project sederhana yang dibuat menggunakan HTML, CSS, dan JavaScript.

Aplikasi ini memungkinkan pengguna untuk menambahkan tugas, menandai tugas yang sudah selesai, dan menghapus tugas.

## Fitur

- Menambahkan tugas
- Menampilkan daftar tugas
- Menandai tugas sebagai selesai
- Menghapus tugas
- Tampilan sederhana dan responsif

## Teknologi

- HTML5
- CSS3
- JavaScript
